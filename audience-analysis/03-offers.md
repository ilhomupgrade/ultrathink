# Офферы для каждого продукта

## Что такое оффер?

**Оффер ≠ Продукт**

Продукт - что вы делаете.
Оффер - почему им это нужно.

**Формула сильного оффера:**

```
БОЛЬ (узнаваемая)
    +
РЕШЕНИЕ (конкретное)
    +
ТРАНСФОРМАЦИЯ (измеримая)
    +
ГАРАНТИЯ (снимает риск)
    +
ДЕДЛАЙН (побуждает к действию)
    =
НЕОТРАЗИМЫЙ ОФФЕР
```
